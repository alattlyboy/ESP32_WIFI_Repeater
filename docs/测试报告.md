## 一、测试方法

分三层验证，每层都有可观测证据，**不靠"看起来能上网"**：

| 层 | 验证什么 | 手段 |
|---|---|---|
| L1 物理/传输 | 两片芯片是否真的通了 | 串口握手日志（chip id / RPC 版本 / 固件版本） |
| L2 链路 | 上行是否关联、是否拿到 IP、NAPT 是否开 | `/api/status` 的 `sta_linked` / `has_ip` / 日志 `NAPT enabled` |
| L3 应用 | 客户端是否真能上网 | ping 网关 → DNS 解析 → HTTPS 200 → `generate_204` 返回 204 |

> **判定标准（重要）**：`sta_linked=true` 只代表空口关联成功，**不代表能上网**；
> 必须 `has_ip=true` 且客户端侧 DNS/HTTPS 都过，才算通过。

## 三、缺陷记录（本次发现并修复）

| # | 现象 | 根因 | 修复 | 验证 |
|---|---|---|---|---|
| D1 | 客户端能连热点、能 ping 通、按 IP 能开网页，但**所有域名解析失败** | `dhcps->dhcps_dns` 默认 0，DHCP Offer 不含 option 6 → 客户端把网关当 DNS，而设备不监听 53 | AP 初始化时（dhcps 仍 STOPPED）预设 `OFFER_DNS`；运行时只 `set_dns_info`，不再 stop/start；另起 **53 端口中继** | T08/T16/T18 |
| D2 | 修 D1 时设备自身 `192.168.4.1` 一度失联（DHCP 正常、公网也通） | 运行时 `dhcps_stop()` 会连 AP 网卡地址一起丢掉 | 改为"启动前设标志、运行时只改地址"，全程不 stop/start | T09 |
| D3 | 校园网 `reason=210 NO_AP_FOUND_W_COMPATIBLE_SECURITY` | 该网络是**开放网 + 网页认证**，被当成企业版去连 → 安全等级不兼容 | 新增第三种认证方式 `eap_enable=2`，`threshold.authmode=OPEN` 且清空密码 | T06 |
| D4 | 扫描要 **10.5 秒** | 5G 位图 `0x1FFFFFFE` 把 DFS 信道（52~64/100~144）也算进来，DFS 必须被动驻留 110ms+ | 改用非 DFS 位图 `0x3E0001E`（36~48、149~165）+ 驻留 30/50ms；扫不到再回退全位图 | P01 |
| D5 | 版本号三处不一致（日志 2.1.0 / 页面 2.2.0） | 版本宏散落在多处 | 统一到 `web_server.h` 的 `WEB_FW_VER` | T19 页面显示 2.2.0 |

## 四、已知限制（非缺陷，物理或策略决定）

| # | 限制 | 说明 | 缓解 |
|---|---|---|---|
| L1 | 扫描时上行断 1~2 秒 | C5 单射频，扫别的信道必须离开当前信道 | 正常现象；扫描结束自动恢复（P05） |
| L2 | 单流吞吐受上级限速 | 直连校园网单流也只有 155 KB/s | 多流并发可到 3.3Mbps；换不限速上级会更快 |
| L3 | 不能同时守 2.4G + 5G | C5 1T1R 单射频 | 架构上就是"5G 收 / 2.4G 发" |
| L4 | 门户登录需客户端代做 | 设备无浏览器；门户按源 IP 授权，NAT 后共用设备 IP | 任一台客户端登录一次，全体生效 |
| L5 | 不支持 EAP-TLS 客户端证书上传 | 无证书管理界面 | 用"电脑开热点共享" |

## 五、稳定性观察

| 项 | 观察结果 |
|---|---|
| 连续运行 | 累计 > 3 小时（含多次扫描、重启、配置切换），无 panic / Guru Meditation / watchdog |
| 上行 RSSI | -48 ~ -56 dBm 波动，未见因信号导致的掉线 |
| 重启原因 | 均为主动操作（烧写 / API 重启）；串口工具打开时 DTR/RTS 会触发一次复位，属正常现象 |
| 内存 | 空闲 180~197 KB，无持续下降趋势 |

## 七、结论

1. **核心功能通过**：C5 收 5G、S3 发 2.4G、单层 NAT，客户端四连测全绿。
2. **校园网可用**：本校为开放网，无需 802.1X、无需门户登录；802.1X 通路也已实现并通过编译与连线验证（本校环境无法实测认证成功）。
3. **性能达可用水平**：聚合 3.3Mbps，1080p 会自适应到 720p，网页/微信无压力；瓶颈在上级限速，不在本机。
4. **遗留风险**：EAP-TLS、Portal 自动登录、VPN 客户端三项未实现，已在文档中标注替代方案。
